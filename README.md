# Helloooo 👋

Helloooo is a real-time social platform for interest-based text, video, and audio conversations.  
**Random people • Real conversations** — connect instantly with strangers who share your interests.

## Live Site

Primary domain: **[helloooo.site](https://helloooo.site)**

## Highlights

- Interest-based matching for group and one-to-one experiences
- Real-time messaging with Socket.IO
- WebRTC video chat with connection resilience improvements
- Creator program with withdrawals and admin tooling
- AI-assisted safety and moderation

## Local Development

```bash
npm install
cd client && npm install && cd ..
npm run dev          # API on :3000
cd client && npm run dev   # App on :5173
```

- `VITE_SOCKET_URL` - Frontend API/socket base URL (optional for local dev)

## Stack

React + Vite + Tailwind · Node/Express · Socket.IO · WebRTC · Supabase
